# ReShade public add-on API

Unmodified API headers from ReShade 6.3.3, commit
`9e3869585db44fda639225243f10dac299e92824` (add-on API 14).
Source: https://github.com/crosire/reshade/tree/9e3869585db44fda639225243f10dac299e92824/include

The headers carry BSD-3-Clause OR MIT notices. The upstream license is retained
as LICENSE.md. TRP resolves the public exports from an already loaded ReShade
module; it neither packages ReShade nor patches its private object layout.
